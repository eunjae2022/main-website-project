# 오픈소스 분석을 통한 에이전시 반응형 웹사이트 커스텀 구축 프로젝트
> **수행 기간**: 2021.03 ~ 2022.11 (고등학교 2~3학년, 약 2개년 진행)  
> **소속 동아리**: 고등학교 공학 컴퓨터 탐구 동아리  
> **개발 인원**: 팀 프로젝트 (고등학생 3명)  
> **사용 기술**: HTML5, CSS3, Bootstrap Framework, Web Deployment

---

## 프로젝트 비하인드 & 타임라인 (미래의 인사담당자님께)
* **작성 시점**: 본 README는 프로젝트를 마친 후 3년이 지난 **2026년**에 작성되었습니다. 
* **개발 배경 (2022년 당시에 대하여)**: 
  당시에는 현재처럼 생성형 AI가 대중화되지 않았던 시기였습니다. 코딩 지식이 부족했던 고등학생 팀원 3명이서 오직 개발 문서와 소스코드만을 붙잡고 역공학 방식으로 웹의 동작 원리를 독학했습니다. 
  특히 모든 템플릿과 공식 문서가 영어로 되어 있어, 기술 용어와 영어를 동시에 공부해가며 2년간 수많은 시행착오와 진땀을 흘려 완성해 낸 눈물겹고 값진 고등학교 시절의 첫 기술적 성과물입니다.
  이 프로젝트를 보실지는 의문이지만 어린시절의 저를 귀엽게 봐주셨으면 하는 바램입니다.

## 1. 프로젝트 개요 및 기획 의도
- **목적**: 외부 오픈소스 웹 프레임워크의 구조를 분석하여 아키텍처를 이해하고, 동아리 및 개인 포트폴리오를 위한 반응형 레이아웃으로 커스텀 빌드하는 것을 목표로 했습니다.
- **역할**: 팀원 3명과 함께 영어 가이드라인 분석, 디렉토리 구조 최적화 및 정적 웹 배포 검토 공동 수행.

##  2. 소스코드 핵심 분석 및 웹 구조
기술적 기반이 없는 상태에서 코드 라인을 하나하나 분석하며 정립한 웹 시스템 구조입니다.

- **컴포넌트 기반 네비게이션**: 단일 페이지 내에서 매끄러운 화면 이동을 제어하는 스크롤 스파이 구조 분석 및 적용
- **반응형 그리드 시스템**: 다양한 디바이스 환경에 대응하는 부트스트랩 가변형 레이아웃 커스텀 수정
- **자원(Asset) 모듈화 및 최적화**: 웹 서버 배포를 위해 템플릿 내 흩어져 있던 리소스들을 체계적으로 분류
  - `bootstrap/`, `css/` : 스타일시트 구문화 및 UI 커스텀
  - `js/`, `inc/` : 외부 플러그인 스크립트 결합

## 기술적 도전과 눈물겨운 성장 지점

1. **AI 없는 시대, 순수 근성으로 이뤄낸 오픈소스 독학**
   - 코드 한 줄의 의미를 알려주는 AI 툴이 없던 시절이었기에, 영어 사전을 찾아가며 오픈소스 템플릿 소스 보기를 분석했습니다. 이 과정을 통해 영어 기술 문서를 두려워하지 않는 대담함과, 모르는 기술을 스스로 탐구해 내는 **'엔지니어링 근성'**을 체득했습니다.

2. **3인의 팀워크와 집단지성**
   - 개발 역량과 어학 능력이 모두 부족했던 고등학생 3명이 모여 각자 역할을 분담하고 협업했습니다. 서로의 코드를 리뷰하고 에러를 함께 밤새워 찾으며, 진정한 팀 프로젝트의 가치와 소통 방식을 배웠습니다.

3. **전기공학과 진학의 훌륭한 밑거름**
   - 기존 결과물을 그대로 복사 붙여넣기 한 것이 아니라, 구조를 이해하고 수백 번 수정하며 완성한 경험입니다. 이때 기른 디렉토리 구조화 능력과 컴퓨팅 사고력은 대학교 진학 후 **C언어 프로그래밍 및 복잡한 전공 프로젝트**를 주도적으로 해결할 수 있는 강력한 원동력이 되었습니다.
