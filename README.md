# 🌐 에이전시 스타일 반응형 웹사이트 빌드 및 구조화 프로젝트
> **수행 기간**: [2022.03 ~ 2022.11 (고등학교 2학년)]  
> **소속 동아리**: [동아리 이름 (예: 공학 컴퓨터 탐구 동아리)]  
> **사용 기술**: HTML, CSS

고등학교 동아리 활동 당시 웹 소프트웨어의 동작 원리를 이해하고, 오픈소스 템플릿의 소스 보기를 분석하여 커스텀 웹페이지를 구축하고 문서화 해 본 프로젝트입니다.

---

## 📌 1. 프로젝트 개요
- **목적**: 부트스트랩 및 컴포넌트 기반 웹사이트의 아키텍처를 이해하고, 클라이언트에게 배포 가능한 수준의 반응형 웹 아키텍처 설계를 커스텀 분석했습니다.
- **핵심 역할**: 오픈소스 코드 구조 분석, UI/UX 디렉토리 아키텍처 설계 및 웹 배포 문서 검토.

## 🛠️ 2. 소스코드 핵심 분석 및 웹 구조
제공된 산출물 파일(`Documentation.html`)을 기반으로 분석한 정적 웹 시스템의 핵심 구조는 다음과 같습니다.

- **컴포넌트 기반 네비게이션**: 상단 헤더 영역에 스크롤 스파이를 적용하여 단일 페이지 내에서 부드러운 화면 이동 기능 구조화
- **반응형 그리드 시스템**: 부트스트랩 그리드를 활용하여 모바일, 태블릿, PC 화면에 모두 대응하는 가변형 레이아웃 채택
- **디렉토리 아키텍처 최적화**: 웹 서버 업로드를 위해 자원을 다음과 같이 체계적으로 분류 및 모듈화
  - `bootstrap/`, `css/` : 스타일시트 및 UI 프레임워크 분리
  - `js/`, `inc/` : 플러그인 및 스크립트 결합도 최적화
  - `video/`, `img/` : 멀티미디어 자원 저장소 구축

1. **오픈소스 분석 및 커스터마이징 능력**
   - 완성된 프레임워크와 외부 라이브러리의 HTML/CSS 소스코드를 직접 뜯어보며 웹 동작 메커니즘을 독학했습니다. 타인의 코드를 분석하고 필요한 형태로 재조합하는 역량을 길렀습니다.

2. **클라이언트 관점의 배포 프로세스 이해**
   - 개발 단계에 머무르지 않고, 외부 사용자가 사이트를 서버에 올릴 수 있도록 인스톨레이션 가이드와 필수 폴더 구조 가이드라인을 문서화하는 경험을 통해 소프트웨어 배포 주기를 이해하게 되었습니다.

3. **엔지니어링 기초 확립**
   - 이 경험은 대학 진학 후 복잡한 전기공학 프로그램 소스코드나 임베디드 웹서버 제어 코드를 다룰 때, 디렉토리 구조를 구조화하고 가독성 높은 코드를 작성하는 강력한 밑바탕이 되었습니다.
